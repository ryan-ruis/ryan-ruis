## 💼 Sobre mim

Trabalho com **suporte técnico em uma plataforma SaaS**, cargo N1 com atuação em casos de maior complexidade e em transição para N2. No dia a dia:

- 🔍 **Investigo e reproduzo** erros para separar bug, regra de negócio, configuração e dúvida de uso
- 🧪 **Testo correções** antes de retornar ao cliente
- 📝 **Documento ocorrências** com passo a passo e evidências para o time de Tecnologia
- 🔁 **Traduzo** problema técnico ↔ linguagem do cliente

Esse trabalho me aproximou de duas coisas que hoje guiam meus estudos: **automação**, para parar de repetir tarefas manuais, e **segurança da informação**, para entender como as coisas quebram e não só como consertá-las.
